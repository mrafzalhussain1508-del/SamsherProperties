# SamsherProperties
🏠 Modern real-estate property platform for discovering and exploring property listings with a clean, responsive, and user-friendly interface.

Built with Next.js, TypeScript, Tailwind CSS, and Framer Motion.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Features
- **Cinematic Landing Page:** Masked staggered text reveals and smooth zoom scale effects.
- **RERA Verified Listings:** Comprehensive property details, direct publishing, and EMI calculators.
- **Role-Based Access Control:** Distinct buyer, agent, and administrative access workflows.
- **SEO Ready:** Dynamic Open Graph metadata, canonical links, and sitemaps.
